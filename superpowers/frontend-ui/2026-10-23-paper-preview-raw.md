# 纸感书房交互原型原始规划

日期：2026-10-23。用户已确认左栏会话分组、中央单窗口、右上知识库与画像、左下账号的布局，并授权制作纸感书房 HTML 探索原型。本次不是正式功能实施。依据：2026-10-23-multi-session-profile-raw.md。主题与画像一一对应仅是此预览的演示假设，正式产品规则仍待定。

## 一、模块总览
独立单文件 HTML，米白纸面、墨绿强调、衬线标题、细线分隔，呈现实际学习空间。覆盖学习对话、知识库、学习画像三视图；无外部依赖、网络、真实账号或持久化。全局明确演示数据与刷新重置。

## 二、子模块概述
会话导航：按主题画像折叠分组，每组会话可切换，账号固定底部；移动端抽屉。对话工作区：独立消息和草稿保存在内存，以明确模拟回复演示；新建弹窗复用或创建主题。知识库：搜索、资源卡片、详情弹窗、本地示例条目增删；不暗示真实上传接通。学习画像：默认当前会话主题，切换主题查看掌握度、薄弱点、来源会话和概念关系；均为拟议能力及示例证据。

## 三、详细实施计划
renderSidebar 根据主题数组及当前会话标识输出分组与选中态。openSession 接受会话标识，更新活动视图并恢复该会话草稿。renderChat 从会话消息列表生成安全转义的对话内容。sendMessage 读取草稿、追加用户消息和标明演示的固定反馈，按原会话写入。createSession 从表单读取已有主题或新主题名称，建立内存主题和会话并选中。renderLibrary 依据搜索文本过滤资源数组；openResource 显示条目详情，addResource 和 removeResource 只修改当前页面内存。renderProfile 根据主题标识输出固定示例指标、知识节点与证据，明确同主题会话共享视图。统一事件代理处理导航及按钮；原生 dialog 支持 Escape 和关闭按钮，用户输入统一转义，窄屏抽屉有遮罩与键盘关闭。

数据：topics 包含 id、name、description、sessions、示例掌握度；sessions 包含 id、title、messages、draft；resources 包含 id、name、type、topic、description。activeSession 和 view 为页面状态；不使用 localStorage。验收：三视图可达、独立草稿和消息不串、创建主题/会话可用、搜索与本地资源操作可用、手机布局无横溢。

## 四、2026-10-23 已确认微调：侧栏固定与收缩

### 模块总览
用户已认可纸感书房布局并要求本次微调。桌面默认展开且固定侧栏；允许主动收起以扩大阅读空间，允许取消固定后切换会话自动收起。保持独立 HTML 与当前页面内存状态，不引入存储或正式接口。

### 子模块概述
侧栏控制区提供固定/取消固定与收起按钮；主栏保留展开入口。布局模块在桌面根据收缩状态释放侧栏空间，手机继续使用原有抽屉，不受桌面收缩状态影响。会话选择模块在取消固定时收起桌面侧栏，固定时维持展开。三视图切换共享控制状态。

### 详细实施计划
新增 sidebarPinned 布尔字段，初始为真；sidebarCollapsed 布尔字段初始为假。updateSidebarState 无输入，通过字段与手机断点同步 body 类、侧栏 inert 状态、按钮标签及 aria 属性；toggleSidebarPin 切换固定字段，固定时展开；setSidebarCollapsed 接受布尔值并同步界面；finishSessionSelection 在会话选择完成后关闭手机抽屉，桌面仅在取消固定时收起。手机菜单与遮罩沿用按钮操作并统一同步辅助状态。断点变化时重置抽屉打开类，恢复桌面字段对应布局；手动展开不改变固定状态，无悬停触发。验证默认固定、主动收缩/展开、取消固定后的会话选择、跨视图状态和手机断点互不破坏。

## 五、2026-10-23 固定含义澄清（替代第四节相应行为）

### 模块总览
用户明确固定的含义为：默认左侧栏与完整主内容同屏可见。桌面使用独立占位的双栏布局，主内容随剩余宽度自适应，侧栏不得覆盖内容。页面完整展示指内容无水平裁切且均可通过各自纵向滚动访问，不要求所有长内容同时出现在一屏。

### 子模块概述
页面框架约束在视口内；侧栏主题列表单独滚动，账号留在侧栏底部；主区中对话/知识库/画像的内容单独滚动，输入框保留底部。桌面固定和取消固定都保持双栏占位，取消固定只解除常驻状态，不推断任何自动收起。窄屏继续使用抽屉，属于空间受限的响应式例外。

### 详细实施计划
为 app、aside、main、workspace、composer-root 补充最小宽高和伸缩约束。主区长单词和链接可换行，网格列允许缩到可用宽度，较窄桌面下画像改为单列。updateSidebarState 更新按钮提示为固定常驻或手动展开，移除选择会话后自动收起文案。setSidebarCollapsed 在桌面手动收起时同步取消固定；展开仍保持未固定。toggleSidebarPin 固定时展开并常驻，取消固定保持当前展开。finishSessionSelection 仅关闭手机抽屉，不改变桌面收展。无悬停或会话切换触发桌面收缩。验收包括默认双栏同屏、侧栏与主区独立滚动、账号与输入框可达、收起释放空间、切换会话/视图保持桌面状态；实际浏览器视觉验收单独记录。

补充响应式边界：大于 480px 的窄面板也默认保留双栏，481–760px 使用 170px 紧凑侧栏，主内容单列、自适应换行，右上入口可换行。仅不大于 480px 的手机宽度使用抽屉；桌面收展断点与脚本媒体查询保持一致。短视口压缩非内容区间距，给列表与工作区保留滚动空间。

## 六、问答页画像缩略样式探索（2026-10-23）

### 模块总览
按用户要求提供三种静态交互样式供选择，沿用已批准的纸感书房双栏布局。缩略图来自当前主题画像，指标为学习掌握度示例，不等同课程完成率或内容权重。

### 子模块概述
A 环形总览配三个知识点细进度，适合快速识别整体与局部；B 横向细进度卡配已掌握和待巩固摘要，适合节省纵向空间；C 分段知识路径展示各知识点百分比，适合查看知识结构。样式切换仅更新缩略容器，不重绘消息、草稿与侧栏。

### 详细实施计划
新增 progressStyle 保存 a、b、c 之一，默认 a。renderProgressPreview 从 current().topic 读取 score、skills、focus，输出当前主题总体、知识点与下一步建议，按样式生成独立区域；没有评估数据时显示待评估。通过 data-progress-style 按钮切换；完整画像入口跳转当前主题画像。窄宽度时卡片自动换行，不增加第三列。验证三样式指标一致、主题切换同步、无评估状态无虚构分数、草稿消息与侧栏状态不丢失。当前会话未绑定结构化知识点，因此仅称“知识点掌握度”，不冒称某一技能就是当前对话知识点。

### 详细实施计划

## 八、已确认悬浮画像上下拖动（2026-10-23）

### 模块总览
用户授权在现有悬浮小卡上增加纵向拖动，右侧位置保持，默认高度沿用当前样式。仅独立 HTML 演示，位置保存在页面内存，刷新重置。

### 子模块概述
定位模块约束顶部导航下沿到输入框上沿之间，展开后重新校正并允许卡片内部滚动；手柄模块使用 Pointer Events 与指针捕获处理鼠标、触摸拖动，区别点击和拖动，保持原悬停、点击和键盘收展；重绘模块在换会话、切视图、窗口缩放时保留及校正高度并清理拖动。

### 详细实施计划
progressTop 保存用户选择的主区相对顶部高度，初始为空；progressDragCleanup 保存当前重绘的清理函数。progressVerticalBounds 输入主区高度、导航下沿、输入框上沿和浮层高度，返回安全上下界及可用高度；positionProgress 读取真实尺寸、设置卡片最大高度并校正定位。收缩入口旁与展开标题栏均提供独立拖动按钮，使用 pointerdown、pointermove、pointerup、pointercancel、lostpointercapture，位移超过四像素才视为拖动；结束抑制随后的误点击，并按是否仍悬停或有焦点恢复收展。手柄上下方向键每次移动十二像素。render 与 renderProgressPreview 在销毁前释放指针捕获并清理状态；窗口 resize 重算边界。验收重点为拖动位置保留、边界不越导航和输入区、短视口滚动、拖动不误开关、页面重绘不遗留拖动状态。
