# 前端视觉方案原始设计 · 2026-10-23

## 授权与边界
用户明确要求依据当前功能制作简单 HTML，提供多个可选的整站重构方案。本产出是独立、可丢弃的探索预览，不修改产品页面，不代表正式实现；正式产品改造须选择方案并确认详细规划。所有数字和对话均为演示，页面不联网、不保存、不执行真实登录。

## 第一层：模块总览
目标是用一个离线 HTML 比较三种完整视觉体系，每种覆盖学习对话、知识库、学习画像和登录。使用原生 HTML、CSS、JavaScript，无依赖。A 纸感书房强调米白、墨绿、衬线标题与阅读留白；B 研究工作台强调炭黑、青柠、紧凑三栏；C 成长空间强调浅蓝、珊瑚与宽卡片。预览与 React、教学 API、数据库完全隔离。

现有功能依据主会话代码核查：教学循环包含掌握度、教学模式和回合；知识库支持名称描述创建删除；画像包含会话数和平均掌握度。历史组件未集成，侧栏历史只作为拟议入口标注；不呈现知识图谱、上传或偏好设置为已接通能力。

## 第二层：子模块概述
1. 预览导航：输入方案标识和页面标识，输出对应布局；状态仅保存在当前文档内存，切换视图不丢失模拟输入结果，刷新清空。
2. 学习工作区：展示示例消息及教学指标；发送仅追加固定演示反馈，空输入提示，使用文本节点避免用户文本进入 HTML。
3. 知识库工作区：名称、描述构成条目，创建和删除仅修改内存数组；空名称阻止提交，名称最长 40 字、描述最长 120 字。
4. 学习画像：只显示示例会话数、平均掌握度，以排版和图形表达不同方向，不新增伪造的已实现统计接口。
5. 登录展示：提交后展示演示说明并切换对话页；不校验身份、不存储凭据、不调用 API。

数据流为用户操作 → 更新局部内存状态 → 重绘视图；导航不改变产品路由。窄屏三栏依次折叠，按钮保留键盘焦点、表单具有标签，减少动态效果偏好得到尊重。

## 第三层：详细实施计划
- render：无输入，读取 theme、page、messages、libraries，输出页面 DOM；每次重绘后绑定表单和按钮事件。
- setTheme：输入 a/b/c，更改根节点主题及方案状态，再重绘，输出所选视觉体系。
- setPage：输入 chat/library/profile/login，更新页面状态并重绘。
- sendMessage：输入字符串，去除两端空白；空值不写入；非空加入用户消息和带演示标识的固定教学回复。消息对象字段为 role、text。
- addLibrary：输入名称与描述，检查名称，生成递增 id，加入 libraries 并重绘；library 字段为 id、name、description。
- deleteLibrary：输入 id，仅过滤该条目并重绘，不触及真实数据库。
- loginDemo：无凭据处理，仅切换至对话并显示提示。
- 所有用户文本通过安全转义渲染；不使用持久化存储、不引入依赖或网络资源。
