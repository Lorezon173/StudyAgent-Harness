原始 `playwright-representative-round1/` 为 25 项、22 通过、3 失败、0 跳过；原日志、截图和附件保留。复核的 E2E 文件 SHA256 为 `294B268A46EDC19726D04DEF3C2E46E38A72757E56BEB836C477205DD1BB87E0`。以下实测使用正式本地 React 页面与内存受控 API，不等于真实后端或原生浏览器文字缩放验收。诊断期间未修改产品、测试或配置；自行启动的 Vite 已停止。

## M2 键盘：关闭断言越过重新进入焦点

原 `keyboard-trace.json` 显示 Escape 后入口保持关闭，Tab 到手柄时 `expanded=false`；再 Tab 到 BODY 仍为 false；Shift+Tab 重新进入手柄时 `inDetails=false`，但 `expanded=true`。第 393 行的 `step(..., closed=true)` 对该步无条件要求 expanded=false，因此失败。原轨迹没有显示关闭详情被 Tab 命中。

Task12 raw 要求 Escape 后抑制当前 focus 立即反开，blur 后重新 focus 可以再开，关闭内容不可被 Tab 访问。最小测试修订应区分关闭期间及离开后重新进入：保留 Escape 后详情不在 DOM/不可 Tab、当前内部手柄转移不反开、焦点离开后的关闭断言，再明确断言重新进入手柄触发展开及后续正常焦点顺序；不能以删除详情不可访问断言代替验证。原失败后续鼠标链未执行，不可称通过。

## M3 短高和双倍字号：实际布局问题与测试操作状态

原失败位于测试第 437 行 `hit(send)`，其前 `long-observations.json` 的数据是在输入之前：600×450 下 composer y=898.02，侧栏列表 clientHeight=0、scrollHeight=14510，账号区 y=498.33、高200.19，消息容器 clientWidth=430、scrollWidth=4169。原始日志没有记录 fill 后按钮中心命中目标。

独立复现使用同样长主题、长会话标题、24 会话、30 条长消息及每个已渲染工作区元素各自计算字号乘二的方法。字体注入是人为压力样本，不应称作浏览器原生缩放。在输入草稿后，`.workspace-content` 已滚动到 501，发送按钮 rect 为 y=474.61、高63.59，中心 y=506.41 超出 450px 视口，`elementFromPoint` 为 null。执行额外的 `scrollIntoViewIfNeeded` 后外层滚动到591，按钮 y=384.61，中心命中按钮；因此不能把输入前的 y=898 当作输入后的原位，也不能断言此按钮完全无法通过滚动触及。但 composer 随外层滚动，并未满足本场景对固定区域锚定与可操作的验收目标，单纯给测试加滚动不能证明该合同。

复现中 `.legacy-chat` 高375px，而长会话 `h1` 高761.5px；`Chat.tsx:35–36` 在纵向 flex 布局直接放置标题，标题占用超出容器后内容溢出至 `.workspace-content`（CSS 为 `overflow:auto`），composer 因此被推出可视区域。侧栏同样处于 450px 高的外壳内：字号放大后品牌、控件、新建按钮、标签和不可收缩账号区合计超高；列表压缩为 0，账号位于可视区外，外壳 `overflow:hidden`。这是该受控压力样本的实际可达性失败，不能推断其他尺寸或原生缩放下必然相同。

长消息样本原附件还记录消息区横向 scrollWidth 4169、clientWidth 430；`MessageBubble.tsx` 渲染 Markdown 的内容区未见针对此长无断点内容的换行设置，实际产生横向溢出。M3 尚未到后续账号、两个容器独立滚动、链接导航和画像正文等断言，这些均未通过验收。最小产品调整应由主会话裁决并先形成三层计划：分别处理长标题对主区高度的挤占、短高侧栏可达性和消息无断点内容的横向溢出，保持原滚动/草稿/锚点合同，不通过缩小注入字号、隐藏内容或删断言掩盖；具体实现及影响需进一步验证。

## M4 移动抽屉：定位器严格模式失败

原日志在关闭会话导航时失败：按名称“关闭会话导航”的非精确 role 定位器同时匹配遮罩及侧栏关闭按钮。`overlay-observations.json` 记录此前移动 touch 打开浮卡、抽屉和账号菜单等步骤；所测账号与退出按钮点均无浮卡几何交集、中心命中自身，不能据此宣称重叠层级通过。

最小建议是给关闭导航定位器指定精确名称，并保留真实 tap、侧栏关闭结果及随后的所有原断言。该轮尚未到受控 503 草稿、退出提示、Escape 或留页步骤；没有证据将 locator 严格匹配失败定性为产品覆盖层故障，也不能称这些后续场景通过。
