01 / THE CHOICE

一眼看懂取舍

PATH A / 局部方案

先复现，再按证据修复

沿用现有控制器、来源核验和原分页合同。只有真实业务 RED 成立时，才增加局部可信冲突次序保护。

获得：更聚焦原问题，变更面较小。
代价：不新增跨批持久续读；复杂历史问题如被证实，仍需另行决策。保留既有安全功能和原真实验收标准。

PATH B / 第八轮方案

扩展长历史恢复能力

在共同复现和冲突保护之外，规划更严分页分类、并发公平调度及 IndexedDB 检查点，支持长历史分批续读。

获得：计划新增暂停、重启后重验和长历史续读能力。
代价：存储、事务、调度和验证复杂度更高；其必要性及实际成本尚未由业务证据证实，并非天然必选。
